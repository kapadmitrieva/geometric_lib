# Документация Geometric Lib

## Общее описание решения. 
**Geometric Lib** - это библиотека на Python, предназначенная для выполнения геометрических вычислений. Она позволяет находить площадь и периметр круга, квадрата, прямоугольника и треугольника. 

## Описание функций

### 1. Круг (circle.py). 
* **area(r)**: Вычисляет площадь круга.
  * *Параметры*: 
    * `r` — радиус круга.
  * *Пример*: `area(3)` -> возвращает `28.274333882308138`
* **perimeter(r)**: Вычисляет длину окружности.
  * *Параметры*: 
     * `r` — радиус круга.
  * *Пример*: `perimeter(3)` -> возвращает `18.84955592153876`

### 2. Квадрат (square.py). 
* **area(a)**: Вычисляет площадь квадрата.
  * *Параметры*: 
     * `a` — сторона квадрата.
  * *Пример*: `area(5)` -> возвращает `25`
* **perimeter(a)**: Вычисляет периметр квадрата.
  * *Параметры*: 
     * `a` — сторона квадрата.
  * *Пример*: `perimeter(5)` -> возвращает `20`

### 3. Прямоугольник (rectangle.py). 
* **area(a, b)**: Вычисляет площадь прямоугольника.
  * *Параметры*: 
     * `a` — первая сторона прямоугольника.
     * `b` — вторая сторона прямоугольника.
  * *Пример*: `area(4, 6)` -> возвращает `24`
* **perimeter(a, b)**: Вычисляет периметр прямоугольника.
  * *Параметры*: 
     * `a` — первая сторона прямоугольника.
     * `b` — вторая сторона прямоугольника.
  * *Пример*: `perimeter(4, 6)` -> возвращает `20`

### 4. Треугольник (triangle.py). 
* **area(a, h)**: Вычисляет площадь треугольника.
  * *Параметры*: 
     * `a` — сторона треугольника.
     * `h` — высота треугольника.
  * *Пример*: `area(3, 4)` -> возвращает `6.0`
* **perimeter(a, b, c)**: Вычисляет периметр треугольника.
  * *Параметры*: 
     * `a` — первая сторона треугольника.
     * `b` — вторая сторона треугольника.
     * `c` — третья сторона треугольника.
  * *Пример*: `perimeter(3, 4 , 5)` -> возвращает `12`
